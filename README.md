# responsive-nft-site
Responsive NFT landing page project.

## Getting Started
Install the dependencies and run the project:

```bash
npm install
npm start
```

## About
This project is a responsive landing page for an NFT storefront concept inspired by the mockup shown in the assignment.

## Project Notes
- Uses Vite for local development and build tooling
- Includes responsive layout behavior for desktop and mobile views
- Styled with custom CSS and a purple premium-brand aesthetic
